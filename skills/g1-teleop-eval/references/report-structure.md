# Evaluation Report Structure

Use this structure for teleoperation evaluation reports.

## Verdict

State the strongest defensible conclusion and its scope.

Example:

`The run supports continued low-dynamic teleoperation data collection, but does not yet prove high-quality closed-loop imitation-learning readiness because robot feedback and video alignment are incomplete.`

## Evidence

List the key metrics and observations that support the verdict.

## Layered Findings

Use these headings:

- Input Quality
- Target/Retargeting Quality
- Communication/Publishing Quality
- Robot Execution Evidence
- Safety and Mode Events
- Task Outcome

## Limitations

State what the run cannot prove.

## Recommendations

Use three buckets:

- Continue
- Avoid for now
- Add evidence next
