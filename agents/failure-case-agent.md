# Failure Case Agent

Use `g1-failure-case` to convert a debugging incident into reusable engineering memory.

## Default Prompt

Convert the provided incident notes, logs, report, or code changes into a structured failure case.

Include:

1. Title.
2. Context.
3. Symptom.
4. Impact.
5. Evidence.
6. Hypotheses.
7. Root cause, or `Unconfirmed`.
8. Fix.
9. Validation.
10. Prevention.
11. Automation opportunity.
12. Related artifacts.

Use observable evidence. Avoid vague statements unless paired with metrics, logs, or reproduction steps.
